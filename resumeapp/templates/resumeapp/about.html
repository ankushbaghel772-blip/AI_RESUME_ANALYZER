About AI Resume Analysis System

An end-to-end Machine Learning, NLP, and Django web application designed to evaluate resumes, extract technical competencies, compute explainable scores, and recommend industry career paths.

System Architecture

The platform follows Django's classic Model-View-Template (MVT) architecture pattern:

  • Presentation Layer (Templates): HTML5, Vanilla CSS3 custom design tokens, subtle 3D card depth, and Bootstrap 5.
  • Business & NLP Services Layer: Text extraction (`pypdf`, `python-docx`), line-based section filtering, boundary-safe regex, and Scikit-Learn TF-IDF classifier.
  • Persistence & Isolation Layer: Django ORM with multi-tenant user isolation, ensuring User A cannot access User B's files.

Scoring Methodology

Our 100-point scoring algorithm is completely transparent and explainable:

30% Sections | 35% Technical Skills | 15% Word Length | 20% Alignment

Unlike opaque black-box checkers, candidates see exactly which areas contributed to their score, providing immediate feedback for enhancement.

How the Processing Pipeline Works

Step 1
Extraction
Converts binary streams from PDF, DOCX, and TXT files into clean unified raw text.
Step 2
Preprocessing
Normalizes whitespace, trims special characters, and preserves syntax terms like C++ and .NET.
Step 3
Skill Recognition
Scans against 60+ industry skills across languages, frameworks, AI/ML, and databases.
Step 4
Career Mapping
Calculates overlap with real-world profiles (Python Dev, ML Engineer, Data Analyst).
Academic & Technical Disclosure

This project provides rule-based NLP extraction and Scikit-Learn TF-IDF machine learning feature extraction. The score is an educational metric measuring keyword coverage and section presence. It does not claim to replicate a proprietary corporate ATS algorithm. Scanned/photocopied PDF files without digital text layers require an external OCR engine (like Tesseract OCR) to extract text.
